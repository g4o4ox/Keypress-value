# Keypress-value

 Enquanto desenvolvia um projeto achei legal trazer um codigo que imprime os valores binarios baseados na tabela ASCII32-126
 nao e algo avancado pra ser sincero e bem simples mas mesmo assim trago aqui para deixar documentado para aqueles que estao aprendendo
 um codigo bem curto.

 parte desse codigo foi baseado na documentacao kilo: https://viewsourcecode.org/snaptoken/kilo/02.enteringRawMode.html
 Voce pode ler a documentacao e entender melhor.
